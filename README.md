# Secure Cloud API DevSecOps AWS

Hands-on Application Security and DevSecOps project simulating a Toyota-style connected vehicle telemetry API environment on AWS.

## Scope
- FastAPI-based telemetry API
- Docker containerization
- AWS deployment with Terraform
- GitHub Actions CI/CD
- SAST, SCA, IaC, container, and DAST scanning
- Logging, monitoring, and incident simulation
